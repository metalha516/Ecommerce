# 🛍️ BSmart — AI-Powered E-Commerce Platform

**BSmart** is a modern, high-performance, full-featured AI-powered e-commerce platform designed for Bangladesh. It includes a consumer marketplace, **Habib AI Assistant**, **Digital Sheba & Utilities**, **Product Comparison Matrix**, **Rewards Hub**, **Live Stream Shopping**, as well as enterprise portals for **Retailers** and **Wholesalers** featuring a **10-Year AI Demand & Supply Chain Predictive Forecaster**.

---

## 🌟 Key Platform Features

### 🛒 1. Consumer Marketplace
- **Header & 3-Mode Search**: Integrated text autocomplete, **Voice Search** (microphone soundwave visualizer), and **Visual Search** (AI image dropzone matching).
- **Flash Sale Banner**: Live countdown timer (`HH:MM:SS`), discount badges (`-25%`, `-35%`), and stock progress bars.
- **Product Detail Modal**: Multi-tab overview (Reviews, Specs, Shipping), color variant selector, quantity stepper, and store perks.
- **Shopping Cart & Checkout**: Slide-over drawer with item controls, promo voucher validation (`BSMART50`), BSmart Coins discount toggle, and bKash / Nagad / Card payment integration.

### 🤖 2. Habib AI Shopping Assistant
- Floating AI sparkle action button & chat drawer.
- Natural language query understanding in Bangla and English (*"Find me a tea gift under ৳1,000"*, *"Compare SSD vs HDD"*).
- Smart product recommendation cards with *Why this fits* breakdown, ratings, and instant compare triggers.

### 🏬 3. Retailer Account Dashboard (`Retailer Hub`)
- **Store KPIs**: Monthly Revenue (`৳4,85,000`), Orders Fulfilled (`1,420`), Avg Order Value (`৳3,415`), Return Rate (`1.8%`).
- **Interactive Analytics**: Monthly sales trend SVG curve with hover tooltips & category share breakdown.
- **10-Year Habib AI Demand & Stock Forecaster**: Leverages 10 years of Bangladesh consumer macro data (2016–2026) and seasonal peaks (*Eid-ul-Fitr*, *8.8 Flash Sale*, *Pohela Boishakh*) to calculate 2026–2027 demand curves, recommended stock reorder units, and projected revenue growth.

### 🏭 4. Wholesaler Account Dashboard (`Wholesaler Portal`)
- **B2B Bulk KPIs**: Gross Wholesale Revenue (`৳28,50,000`), Bulk Shipments (`380`), Verified Retail Partners (`142 Stores`), Warehouse Storage Gauge (`84% Capacity`).
- **Regional Logistics Distribution**: Shipment volume breakdown across Dhaka Central, Chittagong Port Zone, Sylhet Hub, and Rajshahi North.
- **10-Year Habib AI Bulk Procurement Forecaster**: Analyzes import tariffs, dollar rates, container freight indices, and inflation trends to recommend optimal bulk purchase windows and project unit costs.

### ⚡ 5. Digital Sheba & Services
- Mobile top-up recharge (Grameenphone, Banglalink, Robi, Airtel, Teletalk).
- E-Vouchers & Gift Cards (Foodpanda, Uber Eats, Star Cineplex).
- Game credits top-up (Free Fire Diamonds, PUBG UC, Mobile Legends).
- Entertainment Subscriptions (Netflix, YouTube Premium, Spotify).

## 💻 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/metalha516/Ecommerce.git
   cd Ecommerce
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```
   Open `http://127.0.0.1:5173/` in your browser.

4. **Build production bundle**:
   ```bash
   npm run build
   ```
